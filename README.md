## Projects

The portfolio showcases three selected development projects.

### Join

A task management application inspired by the Kanban system.

Join was developed as a group project and focuses on organizing tasks and workflows within a team. The project gave me practical experience in collaborative development, teamwork, Git workflows, and building an application with Angular and TypeScript.

**Technologies:** Angular, TypeScript, HTML, CSS

### El Pollo Loco

A 2D browser game developed with JavaScript and object-oriented programming.

The player explores the game world as Pepe, collects items, encounters enemies, and ultimately faces an end boss.

**Technologies:** JavaScript, HTML Canvas

### Pokédex

An API-based Pokémon library that retrieves and displays Pokémon data from an external API.

Users can browse and search Pokémon and open detailed views containing additional information and statistics.

**Technologies:** JavaScript, REST API, HTML, CSS
